# ZX81 ROMs
Alternative firmware for the ZX81.<br>

## Pluri-Forth by Tree Systems
Implementation of FIG-FORTH.<br>
Note that this original version doesn't work very well on ZX81s or clones that don't have an original Sinclair ULA, i.e. using the vLA81.<br>

There is an updated version by [Mark Beckett](https://github.com/markgbeckett) available [here](https://github.com/markgbeckett/zx81/tree/main/zx-forth).

[Manual](https://archive.org/details/tree-forth/Tree-Forth manual)

## [Big Bang BASIC by Zsolt](https://sinclairzxworld.com/viewtopic.php?t=2986)
Improved/faster BASIC.<br>

## ASZMIC by Comprocsys
Assembler.<br>
[Manual](https://archive.org/details/zx-aszmic-user-manual_202211/ZX ASZMIC User Manual)
